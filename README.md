# Бар на вечер — Android

Офлайн-приложение с 10 коктейлями на белом роме и Jäger Orange. Внутри всё нужное: фото (Unsplash), шрифты Playfair Display и Manrope, иконка.

Готовый APK: `Бар-на-вечер.apk` (debug-сборка, ставится на телефон напрямую).

## Темы
Четыре темы: «Графит» (по умолчанию), «Бордо», «Полночь», «Сливки» (светлая). Переключаются кнопкой с палитрой на главном экране, выбор запоминается.
Цвета — в CSS-блоках `[data-theme="…"]` и в массиве `THEMES` в `www/index.html`. Строка статус-бара перекрашивается плагином `ThemeBarPlugin.java`.

## Что внутри
- `www/index.html` — всё приложение, данные рецептов в массиве `R`, справка в `BASICS`.
- `www/img/` — фото коктейлей (`<id>.jpg`), `www/fonts/` — шрифты.
- `android/` — проект Capacitor 8.

## Пересборка
```
npx cap copy android
cd android && JAVA_HOME=/opt/homebrew/opt/openjdk@25 ./gradlew assembleDebug
```
APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

Сборка идёт на Gradle 9.7.1 + Android Gradle Plugin 9.4.0 с JDK 25: эти версии уже были в кэше на этом Mac.
Шаблон Capacitor ждёт Gradle 8.14 и JDK 21, поэтому в `android/` поменяны версии, а неиспользуемый плагин google-services убран.

## Обновления
Приложение при запуске (не чаще раза в 3 часа) и по кнопке «Проверить обновления» в разделе «Основы» смотрит последний релиз в https://github.com/ZhanKoss/bar-na-vecher/releases.
Если версия новее, предлагает скачать APK и открывает установщик Android. В первый раз Android попросит разрешить установку из «Бар на вечер».

Выпустить новую версию:
```
./release.sh 1.2 "Добавлен коктейль …" "Исправлено …"
```
Все версии подписываются ключом `android/signing/bar.keystore`. Он не хранится в git, держите копию: без него новая версия не встанет поверх старой.

## Как добавить коктейль
Добавьте объект в `R` в `www/index.html` и положите фото `www/img/<id>.jpg` (лучше 900×1100).
В шагах подставляются количества: `{g:id}` — на один бокал, `{b:id}` — на заход шейкера, `{a:id}` — на все порции.
